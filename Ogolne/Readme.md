# Ogólne

Folder zawierający implementacje algorytmów omówionych na wykładach.

## Zawartość

- **Implementacje algorytmów** - różne algorytmy z materiałów wykładowych
- **Język C++** - wszystkie implementacje w C++ dla czytelności i łatwości zrozumienia
- **Komentarze** - każdy kod zawiera szczegółowe objaśnienia ułatwiające naukę

## Struktura

Każdy plik zawiera implementację konkretnego algorytmu z wytłumaczeniami krok po kroku.
